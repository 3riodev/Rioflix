# RIOFLIX

منصة مشاهدة شخصية بتصميم سينمائي داكن. الموقع **ثابت بالكامل (Static Site)** — بدون خادم أو قاعدة بيانات خارجية — كل بياناتك (الملفات الشخصية، قائمتي، التقييمات، متابعة المشاهدة) تُحفظ في متصفحك عبر `localStorage`. هذا يعني: لا تثبيت، لا حساب استضافة معقّد، فقط ارفع الملفات وشغّل.

## كيف تنشره على الإنترنت (3 طرق، اختر الأسهل لك)

### 1) Vercel (الأسهل، مجاني)
1. أنشئ حسابًا على vercel.com وسجّل الدخول بحساب GitHub أو مباشرة بالبريد.
2. من لوحة التحكم اختر **Add New → Project → Deploy without Git** (أو اسحب المجلد كاملًا في صفحة "Import").
3. اسحب مجلد `rioflix` بالكامل (كل الملفات، بما فيها `css/` و`js/`) إلى منطقة الرفع.
4. اضغط Deploy — خلال ثوانٍ يعطيك رابطًا مثل `rioflix.vercel.app`.

### 2) Netlify (مجاني أيضًا، سحب وإفلات فقط)
1. افتح app.netlify.com/drop
2. اسحب مجلد `rioflix` بالكامل إلى الصفحة.
3. ينشر الموقع فورًا ويعطيك رابطًا جاهزًا. يمكنك ربط دومين خاص لاحقًا من الإعدادات.

### 3) GitHub Pages (لو تبي تتحكم بالكود عبر Git)
1. أنشئ مستودع (repository) جديد على GitHub وارفع كل ملفات هذا المجلد إليه.
2. من إعدادات المستودع Settings → Pages → اختر الفرع (main) والمجلد (root).
3. سيصبح موقعك على `username.github.io/repo-name`.

> **ملاحظة عن "قوقل":** جوجل لا يوفر استضافة مواقع ثابتة بواجهة سهلة بشكل مباشر مثل Vercel/Netlify (لديها Firebase Hosting وGoogle Cloud Storage لكن تحتاج إعدادًا أكثر). أسهل خيار فعليًا هو Vercel أو Netlify أعلاه.

## كيف تضيف فيلمًا أو مسلسلًا

1. افتح موقعك المنشور ثم أضف `/admin.html` في نهاية الرابط، مثل: `https://rioflix.vercel.app/admin.html`
2. من القائمة الجانبية اختر **Movies** أو **Series** ثم اضغط **+ Add**.
3. املأ الحقول (العنوان بالعربي والإنجليزي، السنة، الوصف، رابط الصورة والخلفية، الأنواع...).
4. في قسم **Video Source** اختر أحد الخيارين:
   - **رابط سيرفر مضمّن (Embed/Iframe):** الصق رابط التضمين مباشرة (مثال: `https://example.com/embed/12345`). هذا الخيار الأسرع ولا يحتاج أي رفع أو مساحة تخزين.
   - **ملف فيديو مباشر (MP4 / M3U8):** الصق رابط ملف الفيديو مباشرة من استضافتك الخاصة (مثال: `https://yourhost.com/video.mp4` أو رابط بث `.m3u8`).
5. للمسلسلات: أضف موسمًا ثم أضف حلقات داخله، ولكل حلقة اختر نوع المصدر (Iframe أو MP4/M3U8) بشكل مستقل.
6. اضغط **Save** — يظهر العمل فورًا في الصفحة الرئيسية والتصنيفات والبحث.

### التعديل والحذف
من نفس لوحة `admin.html`، كل عمل له زرا **Edit** و **Delete** في الجدول.

## بيانات تجريبية مضمّنة
الموقع يأتي مسبقًا بأفلام قصيرة مفتوحة المصدر (Creative Commons) من مشروع Blender Foundation (Big Buck Bunny، Sintel، Tears of Steel، Elephants Dream) بالإضافة إلى مسلسل تجريبي "Rioflix Open Studio" يوضح نظام المواسم والحلقات — لتقييم الموقع فورًا قبل إضافة محتواك الخاص. احذفها من `admin.html` متى شئت.

## مهم: الملكية والمحتوى
النظام مصمم ليتعامل مع **أي** رابط تضعه (Iframe أو MP4/M3U8) بشكل عام. المسؤولية عن التأكد من أنك تملك حق استخدام أو تضمين أي فيديو تضيفه تقع عليك أنت كمالك الموقع.

## البنية التقنية
- بدون إطار عمل (Vanilla HTML/CSS/JS) — يعمل في أي متصفح مباشرة، بدون خطوة بناء (build step).
- `js/db.js` — طبقة البيانات (localStorage) + البيانات التجريبية.
- `js/i18n.js` — الترجمة العربي/الإنجليزي + دعم RTL كامل.
- `js/ui.js` — عناصر الواجهة المشتركة (الشريط العلوي، البطاقات، الصفوف، الفوتر...).
- `player.html` — المشغّل: يدعم Iframe و MP4/M3U8 (عبر hls.js) في نفس الصفحة.
- `admin.html` — لوحة التحكم الكاملة.
